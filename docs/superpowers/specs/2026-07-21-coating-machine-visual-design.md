# 镀膜机模型视觉优化设计

## 目标

在不覆盖原始 OBJ/MTL 的前提下，把现有卷对卷镀膜机模型调整为适合数字孪生驾驶舱的工业写实视觉：结构清晰、材质有层次、颜色克制，并保持 OBJ/MTL 的兼容性。

## 范围

- 输入：`C:/Users/silicon/Desktop/镀膜机20260702-1_optimized.obj` 与同名 MTL。
- 输出：`C:/Users/silicon/Desktop/镀膜机20260702-1_visual.obj`、`.mtl`、`.blend`，以及一张预览 PNG。
- 保留原始几何、坐标比例和主要对象结构，不做激进减面或对象合并。
- 使用 Blender 脚本完成导入、材质重映射、平滑和导出；MCP 端口 9876 作为可用性依据，命令行脚本作为可重复执行入口。

## 视觉设计

- 主体设备：冷灰色缎面金属，金属度高但粗糙度适中，避免镜面反光吞掉结构。
- 机架与深色部件：深石墨色半哑光材质，用于形成层次和重量感。
- 辊筒/胶辊：深灰或黑色，保留适度高光以显示圆柱形态。
- 观察窗/玻璃：蓝灰半透明，透明度克制，避免遮挡内部结构。
- 工艺和状态部件：少量青色、蓝色、琥珀色作为识别色，不添加大面积发光装饰。
- 所有网格启用平滑着色；在不破坏模型的前提下使用法线加权或轻微倒角提升硬表面观感。

## 预览与验证

- 在 Blender 中创建中性深灰背景、三点柔和灯光和 3/4 视角相机，保存 `.blend` 供人工查看。
- 导出的 OBJ/MTL 必须能被 Blender 再次导入；检查对象数、材质数、顶点/面数量和包围盒均为非空且尺度稳定。
- 原始文件只读，不被脚本写回。
