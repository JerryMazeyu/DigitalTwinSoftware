# 3DM 工业风渲染规格

## 目标

使用 `C:\Users\silicon\Desktop\镀膜机20260721-1932.3dm` 作为唯一模型来源，在不改变模型形态、比例、组件拓扑的前提下，输出一张参考 `C:\Users\silicon\Desktop\微信图片编辑_20260808161758.jpg` 的写实工业风渲染图。

## 范围

- 仅做导入、离散、材质、灯光、相机和渲染。
- 不做删减、拉伸、重拓扑、布尔切割或结构改造。
- 3DM 原始文件保持只读。
- 中间网格只作为内部渲染产物，不作为交付成果。
- 允许为渲染临时下载和缓存补充贴图，但不改变模型几何。

## 视觉要求

- 画面风格参考工业设备实拍，深蓝背景、冷白主光、少量暖色边缘光。
- 设备主体保持金属与涂装质感，避免白模感。
- 材质要贴合参考图：机壳、支架、辊筒、护罩、控制柜、管线、警示件要有不同反射、粗糙度和颜色层次。
- 如果原始文件缺少可直接使用的贴图或材质信息，可以从网上补充工业类贴图资源，例如拉丝金属、喷涂钣金、橡胶、玻璃、地面反射和警示标识贴图。
- 按机台结构拆分成独立集合，重点把卷轴、腔体、辊筒、观察窗、机架分开，避免“整块粘在一起”的感觉。
- 每个腔体单独材质或明暗区分，明确表现“每个腔体不一样”。
- 各组件必须能区分开来，不能整机糊成一个统一色块。
- 优先让这些部分在视觉上分离：机柜、卷料、辊筒、框架、导轨、玻璃/观察件、线缆/管路、危险标识。
- 保留设备层次、阴影缝隙和高光边缘，让结构读得出来。

## 实现思路

推荐流程是：

1. 读取 3DM，保留对象、图层或块实例层级。
2. 按机台结构拆成独立集合，先把卷轴、腔体、辊筒、观察窗、机架等主要部件分离。
3. 将曲面/实体离散为临时网格，但不改几何外形。
4. 按来源组件和腔体位置分配不同材质参数，维持统一工业调性，同时拉开视觉层次。
5. 在 Blender 中配置与参考图一致的相机、背景、主光、辅光和轮廓光。
6. 输出静帧 PNG 和 `.blend` 文件。

备选方案：

- 先在 Rhino 中人工导出网格再渲染，流程短，但可重复性差一些。
- 直接找支持 3DM 的渲染器出图，省转换步骤，但会脱离当前 Blender 工作流。

推荐采用第 1 种，因为它最能保持“形态不变”和“组件可区分”这两个核心要求。

## 验收

- 渲染图与参考图同为工业设备实拍感，不是营销海报风。
- 整机未发生明显几何形态变化。
- 每个主要组件都能在画面中被区分出来。
- 画面没有大面积空白、遮挡、裁切错误或过暗不可读。
- `.blend` 可再次打开并复现同一场景。
